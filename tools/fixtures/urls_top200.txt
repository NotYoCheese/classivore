# Load-test URL fixtures — used by tests/load_test.py with --urls-file.
#
# 200 unique URLs across realistic content classes. The harness samples
# uniformly at random per request, so each URL has equal weight by default.
# To encode a zipfian distribution (e.g., "top 10 URLs see 50% of traffic"),
# duplicate the hot URLs in this file the desired number of times.
#
# Keep URLs broadly stable (sections, homepages, evergreen pages). Article
# URLs that 404 within a few months are fine — they'll show up in the load
# test as 4xx responses, which is itself useful signal.
#
# Sections (commented for readability — comments are skipped by the loader):
#   - Top-tier news (~30)
#   - E-commerce (~30)
#   - Video / social (~30)
#   - Sports / entertainment / lifestyle (~30)
#   - Tech / business / professional (~30)
#   - Long-tail blogs / niche / regional (~50)
